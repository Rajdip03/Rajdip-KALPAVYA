# Kalpavya - A simple eCommerce website

Kalpavya is an open-source **Next.js eCommerce frontend** project.  
It provides a modern, fast and customizable shopping UI.  
---

## Features

-   Built with **Next.js + Tailwind CSS**
-   Responsive design
-   Reusable components
-   Customizable layouts and colors
-   Open for contributions (UI/UX, animations, themes, layouts etc.)

---

## Getting Started

1. Clone the repo

    ```bash
    git clone https://github.com/Rajdip03/Rajdip-KALPAVYA.git
    cd Kalpavya
    ```

2. Install dependencies

    ```bash
    npm install
    ```

3. Run locally

    ```bash
    npm run dev
    ```
