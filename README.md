# Kalpavya - AI Powered eCommerce website

Introducing KALPAVYA — A Full-Stack E-Commerce Platform Inspired by the ancient Indian idea of Kalpavriksha — the wish-fulfilling tree, KALPAVYA represents a modern place where customers can discover and find what they are looking for.  
---

## Features

-   **Advanced Recommendation Engine**: Discover products tailored to your interests and preferences.  
-   **Responsive Modern Design**: A beautiful, user-friendly interface that works seamlessly across all devices.  
-   **Real-time Updates**: Stay connected with the latest products and offers.  
-   **Seller Platform**: Empowering sellers with tools to showcase and sell their products effectively.  
-   **Secure Authentication**: Integrated with Clerk for seamless and secure user management.  
-   **Built with Next.js & Tailwind CSS**: Leveraging the latest in web development for a premium experience.

---

## Getting Started

1. Clone the repo

    ```bash
    git clone https://github.com/Rajdip03/Rajdip-KALPAVYA.git
    cd Kalpavya
    ```

2. Install dependencies

    ```bash
    npm install
    ```

3. Run locally

    ```bash
    npm run dev
    ```
